# big-data

### Seed de la base e-commerce (PostgreSQL)

```
npm install pg bcryptjs
DATABASE_URL=postgres://user:pass@localhost:5432/ma_base node seed.js [--reset]

  --reset : vide toutes les tables avant d'insérer (TRUNCATE ... CASCADE)
```
